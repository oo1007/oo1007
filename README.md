# Hi, I'm julooty

我关注 **AI 产品与效率工具**，尝试把业务问题转化为可以体验、讨论和继续迭代的原型。

这里整理了我的个人项目，主要覆盖企业 AI 场景、数据分析与产品运营，以及 AI 工作流。

**企业 AI 场景 / 多角色流程 / 交互原型**

## 我在项目中关注什么

- **场景与流程**：用户需要完成什么任务，哪些步骤值得简化。
- **原型与交互**：把想法落到可操作的页面，让方案可以被具体讨论。
- **数据与迭代**：明确指标口径，把问题记录与后续行动联系起来。
- **AI 工作流**：将采集、整理和生成步骤组织成可复用的工具。

仓库中的 Fork 用于工具使用与开源学习，个人项目的实现范围和后续计划分别写在对应 README 中。
